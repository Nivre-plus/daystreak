Day Streak Mobile Web App

How to use:
1. Open index.html on your phone browser.
2. Name your streak.
3. Tap "Mark Today Complete" once per day.

For a real home-screen app icon:
- Upload this folder to a simple free static host like GitHub Pages, Netlify, or Cloudflare Pages.
- Open the hosted link in Chrome.
- Tap the three-dot menu > Add to Home screen or Install app.

Note:
Your streak is saved in the browser's local storage. Clearing browser data can erase it.
